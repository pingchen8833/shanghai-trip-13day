# 江南跨年紀行 ‧ 2026/12/24 – 2027/01/05

🔗 **線上瀏覽：https://pingchen8833.github.io/shanghai-trip-13day/**

為家人打造的 13 天江南跨年旅遊網頁：台北 → 上海 → 蘇州 → 湖州太湖 → 南潯 → 烏鎮 → 上海 → 台北。
起點是一份自己排好的 Excel 行程表，因為試算表沒辦法讓爸媽「看了就想去」，所以把它變成手機就能看的互動網頁。

## 功能

- **13 天行程總覽**：點日期展開當天時間軸、交通、費用與住宿
- **每日 Q 版動線圖**：站點依序編號連線，點一下用**高德地圖或百度地圖**開啟
- **景點文化備忘錄**：點景點名稱跳出歷史故事，附 **YouTube 影片與官網連結**
- **預約提醒**：需要事先預約的項目有 🔔 圖示，另有依急迫度排序的預約清單
- **每日一杯**：每天推薦當地飲料店與熱銷款
- **手機優先、深色模式、可列印**：單一 HTML 檔，不依賴外部資源，離線也能開

|---|---|---|---|---|---|

## 製作方式

這個網頁是我**擔任需求方與驗收者，和 AI Agent（Claude）協作開發**的：

- **我負責**：規劃 13 天行程與預算（Excel）、定義使用者（不熟 3C 的爸媽）、逐步提出 13 項需求、在技術限制下做取捨、驗收每一版成果
- **AI 負責**：撰寫 HTML／CSS／JavaScript、查證景點資訊、繪製 SVG 插畫與地圖

### 過程中的取捨

| 遇到的限制 | 決定 |
|---|---|
| 抓不到景點照片 | 改用手繪風格 SVG 插畫，全部內嵌在檔案裡 |
| 高德／百度地圖嵌入需要 API 金鑰 | 改做 Q 版相對位置地圖：「我只要大概、相互的就好」 |
| 分享連結只限組織內部，爸媽打不開 | 改放到自己的 GitHub Pages |

### 行程健檢

請 AI 全面檢查行程，找出並修正 8 個問題，例如：時間重疊、高鐵零緩衝、13.5 小時的超長一天、車程 40 分鐘卻只排 15 分鐘。被取代的行程保留刪除線，看得到更動軌跡。
